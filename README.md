# Northvale University (fictional website)

A responsive fictional university homepage built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. Optional: install the VS Code extension **Live Server**, then right-click `index.html` and choose **Open with Live Server**.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Click **New repository** and name it `northvale-university`. For the simplest setup, make it **Public**.
3. Upload `index.html`, `styles.css`, `script.js`, `robots.txt`, and `sitemap.xml` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes. Your website URL should be:
   `https://YOUR-GITHUB-USERNAME.github.io/northvale-university/`
8. Replace `YOUR-GITHUB-USERNAME` in `sitemap.xml` with your real username, then upload the corrected file to GitHub. If you do this after publishing, wait for GitHub Pages to update.

## Submit to Google
1. Open https://search.google.com/search-console/
2. Add a **URL prefix** property using the full published URL, including `/northvale-university/`.
3. Follow the verification method offered by Google. For a GitHub Pages project URL, use a supported HTML file or meta-tag verification method if offered; if it only offers DNS verification, use another supported method or a domain you control.
4. Once verified, submit `sitemap.xml` using the Sitemaps section. The sitemap URL will be:
   `https://YOUR-GITHUB-USERNAME.github.io/northvale-university/sitemap.xml`
5. Use URL Inspection to request indexing for the homepage.

Google indexing is not guaranteed or immediate. The site can be publicly accessible before it appears in Google search results.

## Notes
- This is a fictional university project. Keep the disclaimer visible.

- The `.example` email addresses are placeholders and will not receive mail.
